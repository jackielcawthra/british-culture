# British Culture — the development of culture in Britain, 1800 to today

A single self-contained HTML page tracing how British culture developed across four eras:

| Era | The shift |
| --- | --- |
| 1800 – 1900 | Culture becomes mass-produced |
| 1900 – 1945 | Culture gets broadcast |
| 1950 – 1979 | Culture belongs to the young |
| 1980 – today | Everyone becomes a broadcaster |

Each era lists the people and places behind it, and every illustration is inline SVG,
so the page has no external dependencies — no fonts, no scripts, no images to load.
Open `index.html` in any browser, online or off.
